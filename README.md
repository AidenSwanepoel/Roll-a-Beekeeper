# Roll a Beekeeper

A bee-themed reskin of *Roll a Fisherman*. See [`docs/BUILD_PLAN.md`](docs/BUILD_PLAN.md) for the full plan.

- `src/` is the Luau source, mapped by `default.project.json` (use [Rojo](https://rojo.space) to sync into Studio).
- `docs/reference/` holds the reference screenshots of the original game.
